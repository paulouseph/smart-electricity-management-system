Smart Electricity Management System

Description
This is a Smart Electricity Management System that helps monitor and manage electricity usage in homes or offices. The system displays real-time usage data and calculates costs for individual appliances based on electricity consumption. It also tracks the **ON/OFF status** of appliances and presents daily, monthly, and appliance-specific usage reports.

Features
- Real-time electricity consumption monitoring for appliances.
- Cost calculation for each appliance based on electricity usage.
- Display of the ON/OFF status of appliances.
- Historical data and reports, including daily, monthly, and appliance-based breakdowns.
- ESP32 integration for data collection and transmission.

Technologies Used
- HTML
- CSS
- JavaScript for front-end functionality
- ESP32 for hardware integration and IoT data transmission
